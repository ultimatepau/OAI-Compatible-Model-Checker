OAI Model Checker

Test which models on an OpenAI-compatible endpoint actually respond, then sync the working set into ~/.config/opencode/opencode.json.

How the check works
  1. Fetches GET /v1/models from the endpoint to list available models.
  2. Sends your prompt to every model via POST /v1/chat/completions — 5 requests in parallel, 15s timeout each.
  3. Active = any HTTP 200 response. Inactive = connection error, timeout, or non-200.
  4. Latency measures the full response, not time to first token.

Pick a provider from your opencode config to fill its base URL, or choose “manual” and paste any OpenAI-compatible endpoint. Only the base URL — /v1/models and /v1/chat/completions are appended automatically.
